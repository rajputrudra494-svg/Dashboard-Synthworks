Security model

Shared by design,
locked by default

SynthWorks is an internal tool, so every colleague sees the same workspace. That is a deliberate choice enforced in the database — not an accident of missing checks.

  • Row Level Security enabled on all 13 tables
  • Anonymous access revoked entirely
  • You can only edit your own profile row
  • The activity log is append-only — no UPDATE, no DELETE
  • Private file bucket served through signed URLs
setup.sql 
-- Shared workspace: any colleague, full CRUD
create policy "read_all_projects" on public.projects
  for select to authenticated using (true);

-- …but your name is yours alone
create policy "update_all_profiles" on public.profiles
  for update to authenticated
  using (id = auth.uid())
  with check (id = auth.uid());

-- The audit log cannot be rewritten
-- (no UPDATE or DELETE policy exists)
